# 项目结构

> 项目：xiaozhi-esp32-server（为 ESP32 智能硬件提供后端服务的开源项目）
> 分支：dev
> 说明：本文基于仓库当前代码整理，路径均相对于仓库根目录。

## 1. 顶层结构

```
xiaozhi-esp32-server/
├─ .github/                     GitHub Actions 工作流与模板
├─ docs/                        项目文档（部署、FAQ、集成指南、架构图、截图）
├─ main/                        所有可运行模块（业务代码都在这里）
│  ├─ xiaozhi-server/           Python 核心服务：语音对话 + 设备通信
│  ├─ manager-api/              Java 管理后端：账号、设备、模型、参数等 REST API
│  ├─ manager-web/              Vue2 智控台前端
│  ├─ manager-mobile/           uni-app + Vue3 移动端智控台
│  └─ digital-human/            数字人测试页 + 本地唤醒词运行时
├─ Dockerfile-server            Python 服务镜像
├─ Dockerfile-server-base       Python 服务基础镜像
├─ Dockerfile-web               Java + 前端合并镜像
├─ docker-setup.sh              Ubuntu 一键部署脚本
├─ Makefile                     测试入口（Python / Java / Web）
├─ README.md                    项目说明与部署入口
└─ mydoc/                       本目录（个人/团队补充文档）
```

## 2. 模块与端口

| 模块 | 技术栈 | 默认端口 | 职责 |
| --- | --- | --- | --- |
| xiaozhi-server | Python 3.10 + asyncio + websockets | 8000（WebSocket）、8003（HTTP：OTA/视觉） | 与 ESP32 建立长连接，完成 VAD→ASR→LLM→TTS 全链路 |
| manager-api | Java 21 + Spring Boot 3 + MyBatis-Plus + Shiro | 8002（context-path `/xiaozhi`） | 智控台后端、为 xiaozhi-server 提供配置、OTA 元数据 |
| manager-web | Vue 2 + Vuex + Element UI + Vue CLI | 8001（开发服务器） | 智控台 Web 界面 |
| manager-mobile | uni-app + Vue 3 + Vite + pinia + alova | 9000（H5 开发） | 移动端智控台，可打包 App / 小程序 |
| digital-human | Python + 原生 HTML/JS + Sherpa-ONNX | 8006 | 数字人测试页、唤醒词检测、事件桥 |
| MySQL | MySQL 8 | 3306 | 账号、设备、模型、参数等业务数据 |
| Redis | Redis | 6379 | 会话与热点配置缓存 |
| MQTT/UDP 网关（可选） | 独立部署 | 见 `docs/mqtt-gateway-integration.md` | 支持 MQTT+UDP 协议的设备接入 |

## 3. main/xiaozhi-server（核心 Python 服务）

```
main/xiaozhi-server/
├─ app.py                    程序入口：检查 ffmpeg、加载配置、启动 WS 与 HTTP 服务
├─ config.yaml               默认配置（含全部可选组件说明，不建议直接改）
├─ config_from_api.yaml      从 manager-api 拉取配置的模板
├─ requirements.txt          Python 依赖（推荐 Python 3.10 / torch 2.2.2）
├─ pyproject.toml
├─ docker-compose.yml        单服务 Docker 编排（8000/8003）
├─ docker-compose_all.yml    全模块 Docker 编排（server + web + MySQL + Redis）
├─ core/
│  ├─ websocket_server.py    WebSocket 服务，每个连接一个 ConnectionHandler
│  ├─ http_server.py         OTA / 视觉分析等 HTTP 接口
│  ├─ connection.py          单个设备连接的状态与消息分发
│  ├─ auth.py                JWT / 鉴权
│  ├─ handle/                消息处理：hello、收音频、文本、函数调用、发音频、打断、IoT、MCP 等
│  ├─ providers/             AI 能力提供者（工厂模式动态加载）
│  │  ├─ asr/                FunASR、SherpaASR、讯飞、火山、腾讯、阿里、百度、OpenAI 等
│  │  ├─ llm/                OpenAI 兼容、Ollama、Dify、Coze、智谱、Gemini 等
│  │  ├─ tts/                EdgeTTS、火山、CosyVoice、Index-TTS、FishSpeech 等
│  │  ├─ vad/                SileroVAD
│  │  ├─ vllm/               视觉大模型
│  │  ├─ intent/             意图识别（function_call / llm / none）
│  │  ├─ memory/             本地短期记忆、mem0ai、PowerMem
│  │  └─ tools/              工具调用相关
│  └─ utils/                 模块初始化、日志、通用工具、缓存等
├─ config/
│  ├─ config_loader.py       读取 data/.config.yaml，并用 config.yaml 补全
│  ├─ manage_api_client.py   调用 manager-api 拉取远程配置
│  ├─ settings.py            全局配置对象
│  ├─ logger.py              loguru 日志封装
│  └─ assets/                绑定提示音、停止播报提示音等静态音频
├─ plugins_func/             插件系统
│  ├─ loadplugins.py         启动时扫描并加载插件
│  ├─ register.py            函数注册、描述与参数 schema
│  └─ functions/             天气、新闻、HomeAssistant、音乐、MCP 等具体插件
├─ models/                   本地模型目录（如 SenseVoiceSmall/model.pt）
├─ music/                    音乐资源
├─ performance_tester/       性能测试模块
├─ performance_tester.py     模型响应速度测试脚本
└─ tests/                    pytest 用例
```

关键运行机制：

- 配置优先级：`data/.config.yaml` > `config.yaml`；使用智控台时，远程配置会覆盖本地配置。
- `selected_module` 决定实际启用的 VAD / ASR / LLM / VLLM / TTS / Memory 实现，由 `core/utils/modules_initialize.py` 动态实例化。
- 每个设备连接独立的 `ConnectionHandler`，互不干扰；支持并发。
- 语音链路：设备音频 → VAD 切分 → ASR 转文本 → LLM（可触发插件/MCP/知识库）→ TTS → 音频流回传设备。

## 9. 数据流概览

```
ESP32 设备 ──WebSocket(8000)──> xiaozhi-server ──HTTP──> manager-api(8002) 拉取配置
     ↑                                  │
     └────── 音频流 / 控制消息 ──────────┘

管理员浏览器 ──HTTP(8001 dev)──> manager-web ──/xiaozhi 代理──> manager-api(8002) ──> MySQL / Redis

设备 OTA 请求 ──HTTP(8002 /xiaozhi/ota/)──> manager-api
视觉分析请求 ──HTTP(8003 /mcp/vision/explain)──> xiaozhi-server
```

## 10. 配置与环境文件

| 文件 | 作用 | 是否提交 |
| --- | --- | --- |
| `main/xiaozhi-server/config.yaml` | 默认全量配置和组件说明 | 是 |
| `main/xiaozhi-server/data/.config.yaml` | 本地覆盖配置（含密钥），由 `config_from_api.yaml` 复制而来 | 否 |
| `main/xiaozhi-server/data/` | 运行数据、日志、密钥 | 否 |
| `main/manager-api/src/main/resources/application-dev.yml` | 数据库、Redis 连接 | 是（本地按需改） |
| `main/manager-web/.env.development` | 前端接口前缀 | 是 |
| `main/manager-mobile/env/.env` | 移动端后端地址 | 是 |
| `main/xiaozhi-server/docker-compose*.yml` | Docker 编排 | 是 |
